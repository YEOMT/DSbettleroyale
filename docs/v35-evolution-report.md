HP 1,920에 30틱마다 계수 20을 가한 별도 표본에서는 기본 14회, 10초 방어 보급 시 22회에 쓰러졌다. 왕귀 III와 REGEN III를 동시에 넣은 극단 시험은 6픽 fixture다. 일반 6레벨 경기에서는 선택 기회가 5회다.

스포트라이트는 36f 예고 후 반경 550 안의 적을 벽 너머까지 180f 기절시킨다. CONTROL 상한은 해당 스킬에서 216f이고 피해는 0, 대기는 1440f다. 미러링은 전방 130에 길이 560·두께 24의 일자 장막 한 개를 300f 설치하고 1320f 뒤 재사용한다. 약한 회귀 유도의 한도는 프레임당 0.045라디안이다. 향후 명시적으로 등록하는 S/F 저격 스킬의 확률은 60/30%다.

## 반사 판정과 복구

네이티브 `Projectile`과 Rework `R.projectile`은 동일한 장막 선분 충돌과 소유권 전환을 사용한다. 방어자 몸은 기존 적중 순서에서 검사한다. 장막은 앞면만 탄을 되돌리며 플레이어 충돌 벽 목록에 들어가지 않는다. 고유 ID, 탄속, 반경, 남은 거리·수명, 탄종, 디버프, 최초 공격자의 왕귀·치명타·공격 보급 스냅샷을 보존한다. 반사자와 생명 번호가 적중·킬 귀속을 넘겨받는다. 원탄의 방향 변화 한 번을 신뢰성 이벤트와 권위 좌표 경로로 전달한다. 동일 시점에는 고정 벽, 농장 상자, 장막, 참가자 순서다.

일반탄·유도탄·관통탄·비행 중 화염구 등 독립 탄체를 지원한다. 연결된 포획 줄, 주인에게 귀환하는 부메랑, 예정된 위치에 떨어지는 포물선 투하물은 운반·회수·착지 계약이 있어 반사 대상에서 제외했다. 접촉 궤도검·근접·돌진·레이저·설치된 장판·이미 발생한 폭발·독·자기장은 비행탄 판정을 거치지 않는다. 다른 피해는 아이언월에도 정상 적용된다.
