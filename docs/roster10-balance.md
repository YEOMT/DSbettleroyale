# Roster10 밸런스 및 상호작용 검사

기준은 최신 main의 기존 77종과 `docs/roster10-spec.md` §3이다. 기존 값은 `tests/baseline/content.json`을 변경하지 않고 대조했다. 전체 활성 87종의 이름·등급·전후 기본 HP·배율은 [기계 판독 결과](evidence/roster10/balance.json)에 기록했다.

## 적용한 최종 값

| 항목 | 이전 → 적용 값 | 유지 사항 |
|---|---|---|
| 기존 B 17종·C 14종 기본 HP | 모든 기존 override 뒤 ×1.06 | 모드·성장 적용 전 한 번; 반경·이동·피해·저항 동일 |
| 기존 S/A/F 46종 HP | 변경 없음 | 기존 유효 기본 스탯 동일 |
| 신규 외계인 B 기본 HP | 258.75 → 274.275 | 동결한 기존 등급/역할 중앙값 뒤 ×1.06 |
| 신규 도깨비 C 기본 HP | 313.467 → 332.27502 | 동결한 기존 등급/역할 중앙값 뒤 ×1.06 |
| 초기 XP 상자 | 기존 최종 목표 ×1.10 반올림, 상한 42 → 46 | 기존 배치 검사·개당 HP/XP·별도 farm RNG |
| 후속 XP 웨이브 | 평균 ×1.10, 웨이브 상한 8 → 9, 최대 상한 48 → 53 | 1200틱 간격·2700틱 웨이브 수명·MAX 레벨/좁은 후반 생성 억제 |
| 회복 웨이브 | 평균 ×1.15, 동시 상한 6 → 7 | 1200틱 간격·2400틱 수명·최대 HP 20% 회복 |
| 부활 모드 전체 상자 | 새 초기 XP 목표 +4 | XP 예약은 새 초기 목표 이내; heal의 추가 4개 공간 확보 |
| 원거리 외향 넉백 | 최종 힘 ×0.88 | 피해·탄속·사거리·기절·저항·기존 강제 제어 구분 |
| 지니 포탑 | HP 70 → 56, 1800 → 1440틱(24초) | 동시 3개, 네 번째 시전 시 가장 오래된 것 교체 |

지니의 기존 최종 정의상 기본/강화 피해 계수는 **15.45 / 27.81**이다. 시전 420틱, 설치 사거리 250, 공격 사거리 780, 발사 간격 42틱을 그대로 유지한다. 이 계수는 등급·증강 등이 적용된 실제 HP 감소량을 의미하지 않는다. 지속시간 증강은 새 1440틱 기준으로 기존 정책대로 적용한다. 공통 포탑 기본값과 다른 포탑 수명은 변경하지 않았다.

초기 상자 실제 배치 수(맵 0, 열린 테스트 전장): 5명 8→9, 8명 10→11, 20명 26→29, 30명 38→42, 40명 상한 42→46. 별도 공중 `SupplyDrop`은 변경하지 않았다.

XP의 생존자 수에 따른 기존 적응 상한은 `min(53, max(12, ceil(alive × 1.6 × 1.10)))`으로 함께 조정했다. 생존자 30명에서도 새 최대치 53을 사용할 수 있으며 기존 최소 상한 12와 후반 생성 억제 분기는 유지한다. XP/heal의 fractional carry는 별개이고 경기 시작/해제 때 초기화한다. 배치 실패한 정수 개수를 이월하지 않으며 놓친 웨이브도 한꺼번에 재생하지 않는다. 파괴·만료된 회복 상자의 재생성 예약까지 개수에 포함한다.

## 넉백의 적용 경계

- native 탄은 원래 힘을 보존하고 표시/적용용 최종 힘에 한 번만 0.88을 곱한다. 상자 명중 파생 폭발의 기존 `max(12, force)` 하한은 **하한 계산 후** 0.88을 적용한다(12→10.56).
- rework 이동 탄·포물선 탄은 출처를 파생 폭발에 전달하고 최종 impulse 계산에서 한 번 적용한다. raw 스킬 계수는 반복 명중·관통 때문에 재곱해지지 않는다.
- native 및 지니 포탑이 실제로 생성한 탄에도 같은 정책을 적용한다.
- 근접 평타·근접 orbit·몸통 dash·hook/capture·명시적 pull·흡입 zone·설치 폭탄의 독립적인 힘에는 이 공통 배율을 적용하지 않는다. 기존 벽 충돌 반응과 기절 시간도 유지한다.
- `ROSTER10_BALANCE`는 방별 승인된 변경값을 모은 내부 정책이다. frozen 전투 fixture는 이 변경값만 이전 값으로 정규화해 기존 assertion을 유지하며, 별도 집중 검사는 실제 기본값을 검증한다. 클라이언트/네트워크에서 이 정책을 수정하는 경로는 없다.

## 실행 결과

| 명령 | 결과 | 실제 Node 검사 시간 |
|---|---|---:|
| `node --test tests/unit/roster10-balance.test.mjs` | PASS 10/10 | 442.8954ms |
| `node --test tests/roster10/interaction.test.mjs` | PASS 13/13 | 529.0327ms |

밸런스 검사는 87종 최종 HP, 기존 77종 불변 기준, 모드 적용 순서, 재생성 시 재누적 방지, 독립 RNG/carry, 배치 실패/누락 웨이브, 상자 수명·예약 상한, native/rework 탄과 파생 폭발, 제외 대상, 실제 포탑 발사와 지니 교체/증강을 검사했다. 8명·10웨이브에서 XP 20→22, 회복 20→23을 실제 생성했다. 동일 fixture의 native/rework 첫 틱 넉백 변위는 모두 **14→12.32**, 피해 **1→1**, 기절 **24→24틱**, 기존 hard-control 여부 **true→true**였다.

상호작용 검사는 실제 native 탄과 근접 평타가 분신/버섯을 파괴하면서 본체 HP·킬·XP·흡혈을 발생시키지 않는지 확인했다. 실제 일반/관통/반사 탄과 기존 beam이 링에 막히고 제거 후 다시 적중하는지, 교차한 두 링의 독립적인 collider 제거, 버섯/회복 상자 앵커의 무피해 자기 이동을 확인했다. 신규 10종 모두 실제 사망→권위 step 처리→KEEP→B/C/본인 리롤을 부활전과 점령전에서 실행해 성장 제거·동일 학생 객체 보존·HP/속도/반경 비누적을 검사했다.

상호작용 검사 첫 실행의 부활 2건 실패는 테스트가 권위 `stepWorld`의 사망 처리 이전에 lifeSeq를 검사한 fixture 오류였다. 실제 step 경로로 수정하고 해당 2건만 재실행한 뒤 추가 상호작용 3건을 포함한 최종 13건을 실행했다. 게임 runtime을 변경해 통과시킨 것이 아니다.
