## 1. 확정 수치: 모든 효과는 해당 경로의 '누적 단계값'

단계 I/II/III는 곱셈 연쇄가 아니라 `tiers[tier-1]`의 **해당 경로 누적 최종값**이며, 서로 다른 경로 조합은 기존 방식대로 `(배율-1)`을 가산하고 최종 상한을 적용한다. 변경하지 않은 보조 페널티·보너스는 원본 유지.

|---|---:|---:|---:|---|

**설계 구분:** 표상 실제 변경 경로는 10개이며, HEAVY/IMPACT는 근접·원거리별 값이 따로 있다. CONTROL의 실효 제어 정책도 같은 경로의 구현 항목으로 취급한다.

### 1.1 수치 예시(무증강 기초·독립 경로 기준)

- 원래 스킬 쿨타임 10초 → QUICK III 3초; 20초 → 6초. 스킬 고유 재사용·채널·연속 사용 규칙은 동일하게 유지한다.
- 이동속도 4.0 → SWIFT III 8.0, **실제 60Hz 이동에 반영**; 고속 이동에 대한 벽/경계 swept collision 유지.
- 스킬 반경 100 → EXPANSION III **실제 피격 반경 250**과 정확히 같은 표시. 원형의 면적은 6.25배일 수 있으므로 서버 공간조회 비용 검사 필수.
- 지속 버프 5초 → AFTERGLOW III 10초가 되는 **해당 능력만**. 스킬 고유 종료·해제·사망·교체·중복 상한이 우선한다.
- 특수 이동기 길이 400 → LONG STEP III 최대 800(벽/장애물/범위/능력별 cap 적용). LONG STEP을 일반 공격 사거리 연장으로 오용하지 않는다.
- 근접 평타 피해 계수 20 → HEAVY III 70(방어·기타 기존 배율 적용 전). IMPACT는 피해 대신 실제 넉백을 변경한다.

## 3. CONTROL — '계수만 증가하고 실제 기절은 그대로' 문제를 반드시 해결

현재 `brRunEffectiveValues`의 기절 프레임 계산과 `rework-core.js`의 `applyStun`은 `skill.stunCap` 및 기본값 `1.35×` 상한을 사용한다. 새 `skillControl=2.25`만 넣으면 기절이 오래전 cap에 걸려 III가 무의미할 수 있다.

### 3.1 기절 실효 상한 정책

- CONTROL을 선택하지 않은 시전은 **현재 v35.6 기절시간과 스킬별 cap을 한 프레임도 바꾸지 않는다**.
- CONTROL 선택 시 정상적인 짧은 제어 스킬만 새 tier-scaled 기절 상한을 허용한다. 제안 정책: `baseStun × multiplier`를 기준으로 계산하되 일반 제어의 절대 상한은 **180f(3초)**, 기존보다 더 낮추지 않는다. 별도로 기록된 특별기 상한은 보존한다. 예: **마이클 잭슨**의 3초 기본 기절·3.6초 고유 상한은 그대로 유지(6초까지 늘리지 않는다).
- 구체적으로 `effectiveCap`은 **능력별 명시적 기존 cap, 제어 강화 허용 cap, 특별기 고정 cap**을 한 곳에서 판정하도록 구현한다. `applyStun`, `brRunEffectiveValues`, 카드 안내가 같은 helper 또는 같은 정의를 사용한다. 기존 특정 기술의 '절대 변경 금지' 상한은 건드리지 않는다.
- 일반 스킬의 예: 1초 기본 기절에 CONTROL I/II/III를 적용하면 **1.4/1.8/2.25초**가 실제로 가능해야 한다(다른 고유 상한이 없다는 조건). 본 예시는 자동 테스트의 기준이다.
- 기절 피해자에게 같은 스킬의 다발탄·틱·AoE가 중복 적용되지 않도록 기존 시전/대상당 횟수, 생명 ID 및 조작 취소 순서를 유지한다.
- 이미 3초 이상인 스킬, 정해진 상한을 초과할 수 없는 궁극 스킬, 0-stun 스킬, 기절이 아닌 넉백/당김 기술을 명확히 분류한다. 0-stun 기술에는 **새로운 기절을 임의로 부여하지 않는다**.
- 기존 `CONTROL` eligible 캐릭터만 대상. 벽 통과·차폐·대상 범위·팀 판정·은신·무적·보호막은 변하지 않는다.

### 3.2 넉백·당김·슬로우

- `c.run.control`이 이미 적용되는 실제 넉백·당김 경로를 새 계수로 강화한다. 벽/경계 내 최종 이동, 기존 강제이동 방지·한 번만 타격·특수기 강제 상태 로직 유지.
- 모든 슬로우에 임의로 제어 배율을 재적용하지 않는다. 각 스킬에서 CONTROL이 실제로 영향을 주는 필드를 감사하고 카드 설명을 조정한다.
- 제어 상한으로 이미 한계인 캐릭터는 과장된 Ⅲ 효과를 표기하지 않는다. III의 **실제 개선이 부족하면** 성능·안전 계약을 위반하는 숨은 효과를 추가하지 말고 검증 보고서에 적고 해당 캐릭터의 카드 자격/미리보기를 정정한다.

## 4. IMPACT — 실제 물리 넉백의 화끈함

- 기본 평타(근접/원거리)에서만 새 `basicKnockback`을 적용. **IMPACT를 선택하지 않은 기본기**, 스킬별 넉백, 장판, DOT, 서포터 기술은 그대로다.
- 근접 III=4.00, 원거리 III=3.25. 맞힌 경우에만 서버 물리·피격 방향으로 밀린다. 헛친 공격은 넉백 불가.
- 벽 충돌 피해가 원래 존재하는 기술만 기존 한 번의 authoritative 벽 피해 규칙을 사용한다. **모든 IMPACT 평타에 벽 추가 피해를 새로 주지 않는다.** 같은 충돌·동일 틱 중복 피해 금지.
- 서버에서 이동량이 클 때도 벽/지형 관통·맵 밖 잘못된 탈락·위치 워프가 없게 sweep·보간·보호·카메라 연출을 점검한다.
- 넉백 연출은 이미 존재하는 피격·벽접촉 몸체 압축/복원을 실제 충돌 방향에서만 재사용한다. 텍스트/광범위 파티클/새 화면 흔들림 없음.

## 5. HEAVY — '강하게 맞히는 평타', IMPACT와 역할 구분

- HEAVY는 **기본 평타의 실제 피해**를 강하게 만드는 경로다. HEAVY 선택만으로 넉백, 기절, 스킬 피해, 고유 벽충돌 피해, 새로운 범위 피해를 증가시키지 않는다.
- ranged III=3.00 / melee III=3.50. I/II도 §1 기준으로 성장. 현재의 I/II 공속 페널티(0.90/0.95), III 기본 공속 유지.
- 실제 `takeDamage` 결과·방어/실드·왕귀·기본탄 분배·치명타·다발탄 규칙과 양립하도록 확인한다. `basicDamage`가 여러 경로에서 곱해지거나 분배 후 다시 더해지는 이중 적용 방지.
- 타격 느낌은 기존 `attack-pose`의 무게별 압축/복원을 필요한 만큼 재활용하되, **기본 공격 준비/입력 처리·발사 타이밍 변경 금지**. 추가 프레임 비용이 확인되면 연출 변경 자체는 생략 가능하며 실제 피해 상향이 우선이다.

## 6. 타 경로별 특화 회귀(반드시 실제 실행 확인)

- **REGEN**: 무피격 프레임 `60f`, 대기 중 HP 변동이 없고 60f부터 초당6.5% 회복. 피해를 받으면 즉시 대기 리셋. 지속 피해 틱, 전투 종료, 사망·부활, 경계 바깥/팀 점령 조건, F급 왕귀·TITAN·HP변환 조합 점검. 단순 HP 경과가 아닌 `lastDamageFrame`과 서버 step 기준.
- **EXPANSION**: 원형/직사각/콘/폭발/장판/투사체 및 native/rework별 `size` 적용이 실제 판정·시각 경고·미리보기와 맞아야 한다. `×2.50`은 반경·폭 등 **길이 축**이지 피해/탄 수 2.5배가 아니다. 기존 방어벽·시야·차폐 예외 유지. 공간 조회/서버 CPU 점검.
- **AFTERGLOW**: 시간 기반 스킬의 실제 종료 시각·상태 해제 및 효과 표시 연동. 포탑·장판 등 능력별 소유자 상한/교체·DOT 중복·상태 refresh 규칙 유지; 스폰 후 생명 교체·사망·재경기 시 과거 기술 무단 잔존 금지.
- **LONG STEP**: 진짜 시전 거리와 조준 가이드를 같은 값으로 늘린다. 추적 갈고리·돌진·순간이동·강제 이동 및 ring/portal/capture 경계·충돌 경로 확인. 특정 능력에 내재한 거리 제한은 명시적으로 보존하거나 변경 이유를 문서화한다. 모든 캐릭터의 기본 이동속도까지 늘리면 FAIL.
- **SWIFT**: 실제 이동 속도 ×2(최종 조합 cap 적용), 입력·보간/예측/서버 결과 일치, 20Hz 스냅샷에서 학생 화면 튐 및 통과 충돌 없음을 확인. 실제 서버 좌표는 정확히 이동해야 하고 시각상 가짜 이동 금지.
- **AMPLIFY**: 자격 있는 스킬 실제 피해 ×2.50(스킬 내 직격·틱·지정된 분배 규칙, 기존 cap·피격 경로 준수). 팀 지원/무피해 제어를 피해 스킬로 바꾸지 말 것. 2.75 전역 상한 이상 확대하지 말 것.
- **QUICK CAST**: native/rework, 스킬 발동·재시전·채널링·비피해 기술에서 쿨타임 0.30이 실제 유지되는지 확인. 단, 시전 중 충돌/발사 프레임·채널 종료·재사용 창을 앞당기지 않으며 소유자 개체 수·공격당 이벤트 한도를 유지. 기존 '최소 n 프레임' 안전 가드 존재 시 충돌하는 캐릭터를 명시하여 카드에 실효 쿨타임을 표기. 별도 공격 연타 자동화 금지.

## 7. 밸런스·체감 실험 설계

- 고정 입력·고정 시드·무증강 vs I/II/III 각각 실제 PvP/봇 표적을 비교. 86종 중 각 스킬 형상/원거리/근접/자격별 대표 캐릭터를 배치하고 **실제 HP 차감/넉백 거리/실제 쿨타임/피격 범위/재생 프레임/기절 만료 시각** 기록.
- 추천 대표: HEAVY(핵주먹·가위 수호자·헤드슈터/사냥꾼), IMPACT(핵주먹·청소반장·다트/볼링), CONTROL(천둥군주·아이스킹·크라켄·마이클 잭슨·청소반장), EXPANSION(폴아웃·역병군주·다이너마이트), AFTERGLOW(역병군주·지니·구급차), LONG STEP(마운틴 팀·로드킬·공허 암살자), REGEN(F/B/C 각1), QUICK(헤드슈터·팬테옹·성역술사·스킬 재시전형).
- 검증 목표는 '모든 상황 승률 상승'이 아니라, **허용된 단계값에 정확히 대응하는 전투 성능과 분명한 조작 체감**. 가령 보스/탱커 방어, 카운터/패링, 회복/부활 등의 역할에 따라 효과의 유효성이 다를 수 있다.
- 중첩 조합 실제 예시: QUICK III+EXPANSION II, HEAVY III+RAPID II, IMPACT III+WIDE II, AFTERGLOW III+QUICK II, REGEN III+TITAN II, LONG STEP III+SWIFT II (각 5회 선택). 자격·제한을 지킨 경우만. 무허용 빌드는 분리 기록.
