공허 광선은 25틱에 걸쳐 무방어 대상의 HP 250을 차감했다. F 5종에서 단계별 최종 HP/공격 배율은 2.00/2.25, 2.85/3.45, 3.60/4.85였다. 벽돌은 왕귀 III에서 HP 1,440이며, 공격 피해 입력 10은 다른 보정이 없을 때 48.5가 됐다. 기존 HP 비율도 유지됐다.

유도 시험에서는 각 동작별로 동일한 다섯 가지 시작 오프셋을 사용했다. 기존/수정 계수를 각각 실제 투사체에 넣고 직선 도주·옆으로 회피·엄폐 진입을 실행했다. 박쥐 스킬의 틱당 최대 선회각은 .055→.048, 심연의 눈 스킬은 .052→.046, 눈 평타는 .045→.040라디안이었다. 두 스킬은 양쪽 모두 직선 5/5·측면 5/5·엄폐 0/5였다. 눈 평타의 측면 적중은 5/5→3/5였다. 탄수는 각각 3·4·1, 피해 입력은 19.57·27.81·18.2952로 같았다.

권위 판정 검사에는 외계인 귀환 경로의 벽·안전지대·다른 몸체·기절·생명 변경·만료, 롤러 강화 평타의 명중·헛침·만료, 가위 첫 발사와 재사용 2회가 포함된다. 가위는 기본 15발, 탄수 증강 시 24발을 발사한다. 재시전 방향과 최초 시각 기준 180틱 창을 검사했다. 신호등은 준비 36틱 후 범위·가시성·팀·보호·신선한 이동 의도·실제 이동을 확인한다. 벽을 밀 때 약 .022 단위만 흔들린 학생이 감속되는 현상을 재현했고, 마지막 완료 틱의 실제 자발 이동이 .1 단위를 초과하는지 검사한 뒤 같은 장면을 통과했다.

20인 격전은 같은 머신의 로컬 WS·학생 브라우저 2개·호스트 1개·가상 학생 18개로 진행했다. 전원에게 탄수 증강을 부여한 가위 3회 발사에서 총 480발, 최대 동시 활성 120개를 측정했다. 서버는 수동으로 3틱마다 실제 WS 스냅샷을 전송했다. 다음 값은 135틱 격전 구간에서 측정한 값이다.

이 조합은 Pixi 호스트에서 프레임 간격과 송신량 부담이 컸다. 프로세스 CPU/RSS에는 같은 Node 프로세스의 Vite·서버·가상 수신자가 포함된다. 분리 서버의 20인 반복 비교는 통합 성능 보고서를 사용한다. 물리 태블릿·학급 실측은 NOT_RUN이다.

각 JSON에는 저사양 모드의 신호등 3화면 표시, 학생 reload/RESUME 후 외계인 귀환, 같은 방 Results/Rematch와 격전 샘플이 있다. 최초 캡처에는 전투 중 fixture가 참가자 생명을 교체하면서 이전 입력이 거절된 `LIFE_MISMATCH` 알림이 보인다. 이 실행은 벽 고정 이동 예외와 신호등 제어 증강 자격의 최종 보완 전이다. 두 보완은 집중 단위 검사로 확인했다.

로컬 재현은 `node --test tests/unit/v34-roster.test.mjs`와 `node tests/combat/v34-roster.mjs canvas`, `node tests/combat/v34-roster.mjs pixi`를 사용한다.

PR #19 CI 43018289605에서 Pixi 학생 감속 단언이 실패했다. 원본 CI에는 발동 틱의 입력과 위치가 없다. 실제 키를 누른 학생의 브라우저 입력 샘플러를 경고 화면 캡처 후 지연시킨 로컬 재현은 30.491초에 같은 단언에서 실패했다. 발동 200틱에 마지막 이동 입력은 176틱이었고, 250ms 이상 지난 입력은 중립 상태로 처리됐다. 대상은 부채꼴 안에 있었고 시야가 열려 있었으며 이동 잠금도 없었다.

시험에서는 매 3틱을 진행하기 전에 실제 학생의 새 걷기 입력이 WS로 도착하는지 확인한다. 인위적으로 전투 중 생명을 교체하던 준비 과정에서도 48.779초 TIMEOUT이 발생해, 같은 20명의 실제 배정과 같은 방 재경기로 세 장면을 준비했다. 수정 Pixi 시험은 60.963초에 통과했다. 발동 37틱에 실제 걷기 입력 나이는 0ms, 직전 틱 전진은 4.563이었고 서버 감속은 0.35였다. 가위 480발에서 호스트 draw p95는 49.9ms, frame gap p95는 64.5ms였다.
